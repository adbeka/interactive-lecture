# Какую архитектуру выбрать? — лекция-исследование

Интерактивная лекция по дисциплине «Проектирование информационных систем» для студентов ОП «Информационные системы».

**Автор:** Аденов Бекасыл, магистрант гр. ИС-26 МН, Алматинский технологический университет.

- **Открыть лекцию:** https://adbeka.github.io/interactive-lecture/
- **PDF-версия** (для преподавателя, с ответами и рабочим листом команды): [lecture.pdf](lecture.pdf)

## Как устроено занятие

1. **Мотивация** — загадка «почему портал падает в первый день записи на дисциплины?», интуитивное голосование и три безымянные системы A, B и C.
2. **Исследование** — случайные команды, источники, лаборатория из 4 экспериментов: прогноз → эксперимент → свой вывод → понятие.
3. **Игра «Выживет ли ваша система?»** — команды собирают архитектуру на 10 монет, затем случайные события проверяют её на прочность.
4. **Творческая мастерская** — история в жанре по жребию, где должны прозвучать все ключевые понятия; проверка терминов без ИИ.
5. **Защита и рефлексия** — выступления команд и голосование только за чужие команды, самооценка.

Через всю пару идёт рейтинг команд: очки за прогнозы, ключевые слова, игру и голоса, минус за нарушения правил ИИ.

Лекция — один HTML-файл без зависимостей (anime.js встроен), работает офлайн. ИИ-консультант с ограничениями работает только в версии, открытой в Claude.
